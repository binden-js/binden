# Security policy

## Supported versions

Only the latest release of the packages of this repository (`binden`, `@binden/logger`,
`@binden/body`, `@binden/compression` and `@binden/multipart`) gets security fixes.

## Reporting a vulnerability

Please do not report vulnerabilities in public issues. Report them privately through
[GitHub](https://github.com/binden-js/binden/security/advisories/new) (Security → Report a
vulnerability), with the affected package and version, and the steps to reproduce.
