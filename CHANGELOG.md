# Changelog

Since 4.0.0, all packages of this repository (`binden`, `@binden/logger`, `@binden/body`,
`@binden/compression` and `@binden/multipart`) are released together with one version. The notes of
every release are published as [GitHub Releases](https://github.com/binden-js/binden/releases).

The history of the earlier versions is kept in the changelog of each package:

- [`binden`](packages/binden/CHANGELOG.md)
- [`@binden/logger`](packages/logger/CHANGELOG.md)
- [`@binden/body`](packages/body/CHANGELOG.md)
- [`@binden/compression`](packages/compression/CHANGELOG.md)
- [`@binden/multipart`](packages/multipart/CHANGELOG.md)
